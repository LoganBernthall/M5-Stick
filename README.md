# M5 StickC Plus Projects

A mixture of random projects on the ESP32 Arduino unit. 

---
## Purpose:

The purpose of this repo is to explore the M5 Stick C Plus in a variation
of rather random projects.

---
## Projects:

[WiFi Scanner](https://github.com/LoganBernthall/M5-Stick/tree/main/WIFIScanner) 

* A simple scanner that looks for networks and displays if they are 
open or closed.

---
[PCStatisticReader](https://github.com/LoganBernthall/M5-Stick/tree/main/PCStatisticReader)

* A Powershell script which gets system details, creates a HTTP server wherby the M5
picks up the data posted and displays.
---
[Pong](https://github.com/LoganBernthall/M5-Stick/tree/main/Pong/ESP32Pong)

* Pong on ESP32!

---
[FakeAP](https://github.com/LoganBernthall/M5-Stick/tree/main/FakeAP/ESP32FakeAP)

* IN PROGRESS - Plan to be a Fake AP for education and ethical purposes only.
